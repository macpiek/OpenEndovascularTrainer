# Strain-preserving geometric bias — optional bounded prototype

The optional `preserve-strain` variant removes the elastic deformation introduced by the compliant bias on the tilted stress-free plane witness. It also passes the unchanged eight native World oracles. The translated-mouth case still fails final physical contact closure. The default bias option remains `physical-compliance`.

Enable per joint, between timesteps:

```js
import { configureKirchhoffSplitBias } from './src/physics/kirchhoffSplitMotion.js';
configureKirchhoffSplitBias(joint, { materialMode: 'preserve-strain' });
```

Only CoupledSystem and SplitMotion production sources change. World, physical EI/GJ/compliance, rest data, tolerances, damping, force gradients, inverse-mass metric and solver backend are untouched.

## Equations

The physical phase is identical in both variants. It solves the native material equations and captures `C_phys` before geometric bias. The existing compliant bias solves

`(C_geo - C_phys) + alpha_physical * lambda_bias = 0`.

The optional variant instead solves

`C_geo - C_phys = 0`, with `alpha_bias = 0`.

Thus each coupled material bias row has RHS `-(C_geo-C_phys)` and zero diagonal compliance. This changes neither the native material assembly nor the physical multiplier bank. The bias convergence measurement uses exactly the same hard strain difference. After restoring physical multipliers, the final material gate still evaluates fresh `C_geo + alpha_physical * lambda_physical`; the old phase residual is never substituted for it. No new Newton loop or outer reclosure was introduced.
