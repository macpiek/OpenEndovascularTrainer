## Public contract

```js
const result = solveKirchhoffCoupledSystem(constraint, dt, {
    tolerance: 1e-8,
    apply: false,
    basis: 'common-relative', // default; 'individual' is the full oracle path
    additionalRows,
    groups,
});
if (result.diagnostics.converged) {
    applyKirchhoffCoupledCorrection(constraint, result, result.scale);
    // Caller accumulates scale * contactIncrement and additionalIncrement
    // exactly once into the manifold/boundary/friction state.
}
```

`constraint` supplies `innerBody`, `outerBody`, existing `kirchhoffContacts`.
Normal records retain cubic/multipoint or two-node stencils, `normal`, `gap`,
`_normalAlpha = compliance/dt²`, `manifoldContact.normalLambda`.
Default normal gradients are minus inner / plus outer. Optional
`record.normalGradients:[{side,dof,value}]` overrides that entire stencil,
including angular moment derivatives. Repeated contributions are summed.

Results `inner` / `outer` own full generalized `correction`, material `lambda`
increments, active ranges and redundant-boundary metadata. `contactIncrement`
and `additionalIncrement` are unscaled. `scale` is one common trust-region scale
for positions, frames and every multiplier increment. The apply helper changes
positions, frames and MATERIAL multipliers only. It does not change normal or
friction/boundary multipliers or attribute the full direction to toolProjection.
It rejects unconverged results and changed active ranges.

Dry assembly changes no material/normal multipliers, including redundant pinned
rows. It enforces an already prescribed orientation boundary, as the solo solver
does. Redundant pinned adaptation multipliers are cleared only during application.

Successful solves update only boolean `manifoldContact._jointActive` and
`additionalRows[].activeHint` (disable with `updateActiveHints:false`). They
retain no forces and survive fixed-step multiplier resets and contact reordering.
Results include `contactActive` / `additionalActive`; a caller rebuilding
boundary rows must persist their hints by identity. Every omitted inequality is
still checked and may activate or release.

Additional rows:

```js
{
    strain, alpha, lambda,
    lower: -Infinity, upper: Infinity, // TOTAL multiplier bounds
    gradients: [{side: 0, dof: node * 6 + axis, value}],
    coordinate, activeHint, // optional
}
```

Axes 0–2 are WORLD translation; 3–5 are LOCAL right-multiplied material-frame
rotation. The final node has translation only. These rows support wall, sheath,
control, fold, tangential surface displacement and spin without world private APIs.

Friction groups are disjoint pairs, with indices RELATIVE to `additionalRows`:

```js
{type:'coulomb-disk', rows:[u,v], radius: mu*fixedFn}
{type:'coulomb-ellipse', rows:[u,v], radii:[muU*fixedFn, muV*fixedFn]}
// Surface helper alias:
{kind:'coulomb-ellipse', rowIndices:[u,v], mu:[muU,muV], normalLambda:fixedFn}
```

The radius/load is FIXED for this solve. No derivative of friction radius acts
on normal forces: normal load cannot be increased to buy more friction capacity.
Normal forces can still change through genuine mechanical cross-coupling.
The parent updates fixedFn between joint relinearizations and must check that
final friction lies within the final normal-load envelope. It must not apply a
separate post-friction correction. Zero load/axis reduces exactly to a point or
force interval; no independent rectangular approximation replaces a positive 2D
ellipse. Grouped rows require otherwise unbounded force bounds. Row groups cannot
overlap. normalContact metadata is not used by the solver.

`assembleKirchhoffDirect` exports column-sparse J, W, C/strain, alpha, lambda and
RHS `-C-alpha*lambda` without factorization. `assembleKirchhoffCoupledSystem`
exports complete ordered rows, columns, matrix, bounds and bundle. These arrays
are borrowed until the next assembly; solve correction/multiplier results are
owned snapshots. `includeSystem:true` attaches the borrowed assembly.

## Model and algorithms

The complete dual operator is `A=J W Jᵀ+alpha`. It contains both rods' material
rows, normal contacts and additional rows. Rest curvature, anisotropic EI, GJ,
independent local twists, axial slide, free exposed rod and all physical dofs are
retained. No material-force cap, EI averaging, shape target or material Schur
complement is introduced.

Rows interleave by material arc; existing contact correspondences estimate the
longitudinal offset. `axialCoordinates` can supply exact ordering coordinates.
Default bundle CSR exactly transforms paired translations and the inverse-mass
metric to common/relative coordinates, then recovers both original axes from
that basis. Unpaired coordinates and all angular frames remain independent.
`basis:'individual'` retains the original columns as an oracle. Common-relative
is a coordinate change, not a reduction or automatic speedup. Its union support
may widen the band; the actual bundle band is computed before allocation.

The normal/box QP uses a feasible working set. Only the FREE PRINCIPAL MATRIX
is compressed/factored; every bound row remains in the full residual at its
current multiplier. This preserves all inequalities. Changed working sets get a
new factor; refinements reuse it. Exact zero-mobility rows never block activation
of mobile inequalities, but their original residual remains visible and prevents
convergence if the requested tolerance is too tight. Bounds are hit through line
parameters at machine precision, not an absolute small-force cutoff.

For friction, active positive-load ellipses are solved in their force tangent.
The active-boundary Lagrange curvature adds a positive Hessian term. This creates
a banded SPD reduced Newton problem for material, normals and friction together.
Only a constrained force-domain radial variable is eliminated; no rod dof is
removed. Interior ellipses use both force components and exact boundary
intersection; active ellipses retract along the ellipse. Objective line search
and a projected-gradient safeguard maintain feasibility and descent.

The factor is always a PSD Gram/proximal system, never ordinary Cholesky on an
indefinite KKT. Numerical diagonal equilibration, a `1e-12` proximal shift and the
existing kernel pivot floor are numerical preconditioning only. Every residual
and convergence test uses the ORIGINAL unshifted equations. Near-null rows remain
constraints. `nearNullPivots` is a warning, not an exact rank certificate.
Refinement/active-set/cone limits return explicit nonconvergence, never physical
softness or a silently applied incomplete direction.

`reconstructionResidual` independently evaluates `rhs-J*correction-alpha*delta`
through the recovered physical dofs. For sliding groups, only a legitimate
outward normal to the fixed ellipse is removed from the KKT residual. This
second check must satisfy the same tolerance. `materialResidual` is the LINEAR
Newton equation residual, not the nonlinear strain after other world operators.
Since the direct model uses `C=edge-L*R(q)e3` with normalized R, exact adaptation
implies exact length: `abs(length-L) <= norm(C)` for a unit director.
