# Initial wall penetration: direction stabilization experiment

Production update: the numerical method has now been integrated and tested. See [production implementation and 752-test validation](production.md). The private experiments below are historical evidence from before that integration.

Root investigated the preserved .011 mm initial wall penetration witness from `tests/kirchhoffCompositeJointWorldAdapter.test.js`. The authoritative production source remains unchanged and still rejects that case. This experiment changes the numerical search-direction equations in a private snapshot, while the final nonlinear force, torque, length, boundary, contact and Coulomb certificates remain exactly the production criteria.

The failing 38×38 matrix has estimated NumPy 2-norm condition 1.337e16 (physical units), 2.644e12 after existing diagonal scaling. Its largest Newton increment is 1.167e8. A separate NumPy dense solve also gives a force residual of order 1e−8, corroborating a conditioning problem rather than a simple band-solver indexing defect. Two iterative corrections plateau at 6.864e−9, above the unmodified linear 5e−10 requirement; eight corrections do not help. The raw original matrix, scaled-system inputs and direction are preserved in `system.json`.

A primal-only positive diagonal regularization did not resolve the failing direction. A positive diagonal shift of 0.01 in the scaled **whole numerical primal/dual system** gave an accepted nonlinear result in 10 directions / 77 evaluations when used from the initial iterate. This is a numerical search method, not added physical compliance, and no shifted residual replaces the final physical acceptance criteria. It is not an original Newton direction: a production implementation must keep its numerical-system proof explicitly separate from the original unshifted proof.

Activating the same shift only after the existing linear failure was too late: shifts .01/.1/1 all ended in line-search rejection. A private early trigger instead refuses an unregularized trial alpha below 1e−4, restores all candidate geometry, multipliers, wall chart, lumen and wall traction, and reassembles at the same pre-trial state before enabling the 0.01 direction shift. This succeeds in 11 directions / 92 evaluations. Its original final force residual is 4.543e−8 (limit 1e−7), torque 7.840e−15, length 2.657e−11 and boundary 2.619e−11; the original wall/lumen/friction certificates converge. This is evidence for globalization before accepting a tiny step, not a validated choice of universal shift or trigger.

No production module was changed. The private prototype is deliberately not production quality: environment variables control the numerical method, the direction helper temporarily measures the modified matrix under its old internal proof field, fallback budgets/retry ownership are not fully implemented, and only this witness was examined. The full solver's physical final certificate remains unmodified. Production integration must provide distinct regularized/unshifted proofs, bounded/accounted attempts, exact restoration and cold/reuse/retry parity, unchanged behavior for normal cases, and performance validation. The 92-evaluation case is not a 60 FPS result.

The private snapshot is `/tmp/oet-world-wall-penetration-probe`. Run `OET_EARLY_TRUST=1 node /tmp/oet-world-wall-penetration-probe/probe.mjs` to reproduce the early-trigger result; `OET_PRIMAL_SHIFT=0.01` enables the current whole-system shift from the start despite that experimental variable's earlier name. The stored production-source hashes prove the root timestep and direction solver remained unchanged. This finding determines the next numerical implementation step; it does not complete source-constraint, moving-mesh or UI integration.
