Jak uruchamia się aplikacja

index.html buduje ekran ładowania i panele sterowania, a src/bootstrap.js asynchronicznie importuje symulator. Błąd startu pozostaje widoczny dla użytkownika zamiast kończyć się pustym ekranem. Vite udostępnia moduły ES i zasoby Three.js.

index.html→bootstrap.js→simulator.js→pętla 120 Hz + render

Po załadowaniu STL aorty, szkieletu i skompilowanego pola kolizji symulator tworzy scenę, kamerę, narzędzia, świat XPBD, model przepływu kontrastu oraz interfejs. Funkcja animate(time) dzieli czas na stałe kroki fizyki i osobny render klatki.

Architektura

Scena

simulator.js spina cykl życia, zasoby Three.js, warstwy debug/fluoroskopii i benchmark.

Anatomia

aortaModel.js ładuje STL i pole kontaktu; boneModel.js ładuje OBJ szkieletu.

Narzędzia

Drut i cewnik są ciałami prętowymi w jednym świecie XPBD. PigtailCatheter zarządza kształtem końcówki i instancjami renderera.

Obraz

Osobne cele renderowania i shadery tworzą grubość, szum, persystencję, DSA i roadmap.

Najważniejszy przepływ danych

  1. Wejście z klawiatury i UI ustala prędkość wsuwania, obrót, parametry C-arm i iniekcji.
  2. stepSimulation(dt) aktualizuje materiał narzędzi oraz rozwiązuje więzy i kontakt.
  3. System kontrastu transportuje masę po grafie naczyń i generuje lokalny pióropusz 3D.
  4. Pozycje są kopiowane do buforów instancji; warstwa fluoroskopii wykonuje kolejne przejścia shaderów.
  5. Monitor i odczyty UI pobierają stan bieżącej procedury.

Fizyka narzędzi i kolizje

EndovascularPhysicsWorld utrzymuje wspólny, deterministyczny świat XPBD. Kolejność rozwiązywania obejmuje światło introduktora, długość segmentów, zginanie i kształt spoczynkowy, zawieranie drutu w cewniku, kontakt narzędzie–narzędzie, ścianę naczynia oraz tarcie Coulomba.

  • VesselContactField odczytuje rzadkie SDF z pliku res/Aorta_plain.collision.bin i zwraca odległość, normalną oraz projekcję do światła.
  • PackedLumenField dekoduje przekroje, osie i cegły pola bez kosztownego preprocessingu przy starcie.
  • createCenterlineCapsuleBroadPhase() ogranicza liczbę kandydatów kontaktu i udostępnia diagnostykę przepływu.
  • GuidewireResistanceModel przekłada kontakt, krzywiznę i ruch na opór odczuwany przez sterowanie.

Tryb produkcyjny to xpbd-contact-v1; parametr URL ?physics=legacy uruchamia porównawczy model ElasticRod.

Kontrast, fluoroskopia i DSA

HybridContrastSystem łączy zachowawczy transport 1D po pełnym drzewie środkowym z lokalnym pióropuszem 3D przy wylocie. Hydraulika przelicza wybraną objętość i tempo na czas, ciśnienie i przepływ; sieć rozdziela masę na rozwidleniach, a renderer buduje siatkę wypełniającą światło.

DSA przechodzi przez stany zdefiniowane w dsaRoadmapState.js: rejestrację maski i klatek kontrastowych, cine, wybór zakresu oraz kompozycję roadmap. Funkcje w simulator.js archiwizują tekstury, usuwają stare klatki i tworzą miniaturę bez blokowania fizyki.

Rozwój, zasoby i testy

npm install
npm run dev             # serwer Vite
npm test                # składnia + testy regresji
npm run build           # produkcyjny katalog dist/
npm run docs:generate   # odśwież indeks tej strony
npm run docs:check      # sprawdź, czy indeks jest aktualny
npm run collision:build # przebuduj binarne pole kolizji

Po zmianie STL, transformacji aorty albo algorytmu preprocessingu należy odtworzyć asset kolizji i wykonać pełne testy. Testy w tests/ sprawdzają m.in. zachowanie masy kontrastu, DSA, stabilność XPBD, tarcie, opór drutu, broad phase i regresje geometrii.

Cel automatycznej aktualizacji

Workflow .github/workflows/documentation-goal.yml uruchamia się po każdym pushu na main lub master, czyli także po merge pull requestu. Generuje indeks bez wywołań sieciowych, wykonuje kontrolę dokumentacji, testy i build, po czym zapisuje zmieniony HTML. Commit bota zawiera [skip ci], a dodatkowy warunek aktora zapobiega pętli.

Generator skanuje wszystkie pliki JavaScript w src/, więc nowy moduł, funkcja albo klasa automatycznie pojawia się w indeksie po merge. Opisy architektury są redagowane ręcznie, aby wyjaśniały intencję, a nie tylko powtarzały sygnatury kodu.
